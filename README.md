## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/MyPortfolio.git
```

Move into the project folder:

```bash
cd MyPortfolio
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Flask app:

```bash
python app.py
```
